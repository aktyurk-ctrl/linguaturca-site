## SEO и маршруты

- Единая App Router metadata: `metadataBase = https://linguaturca.ru`, уникальные title/description/canonical/Open Graph/Twitter для главной, списка статей, трёх статей, политики и оферты. Домен взят из существующих юридических документов и SEO-настроек, а не придуман.
- Действующие адреса `/articles`, `/policy`, `/legal` сохранены. `/blog`, `/blog/:slug`, `/privacy`, `/offer` перенаправляются на них с HTTP 308.
- `app/robots.ts` закрывает `/api/` и объявляет sitemap. `app/sitemap.ts` включает главную, список статей и три статьи. `/policy` и `/legal` сохраняют намерение прежнего `noindex`, теперь через работающий Metadata API, с `follow`; в sitemap их нет. Фиктивных дат обновления нет.
- Проверены favicon, Apple icon и оба Android icon. Исправлены пустое имя и неверные пути manifest. OG-картинка 1200×630 статически генерируется по `/og`, использует локальный шрифт и существующий слоган, без внешних изображений.
- Удалены `next/head` из документов, неподключённые `SeoProvider`/`src/seo/default.ts`, `next-sitemap.config.js` с example-доменом и старый npm script sitemap.
- JSON-LD: EducationalOrganization, WebSite, Article и BreadcrumbList. Breadcrumbs действительно видимы на внутренних страницах. Заголовок Article совпадает с h1. Не добавлены неподтверждённые авторы, даты, ratings, reviews, статистика или курсы с неподтверждёнными offer-данными.
- HTTP-проверки всех SEO endpoints, canonical, метаданных, JSON-LD и redirects сохранены в evidence. Подход соответствует [Metadata API Next.js](https://nextjs.org/docs/app/api-reference/functions/generate-metadata).

## Cookie / analytics

Обе существующие аналитики — Yandex Metrica и Vercel Analytics — загружаются только после сохранённого `accepted`. До выбора и после `declined` нет запросов к скриптам аналитики. Отказ сохраняется, а повторный выбор доступен в footer. Отзыв согласия перезагружает документ, чтобы уже инициализированный сторонний код не продолжал работу; изменение выбора в другой вкладке также перезагружает документ. Vercel дополнительно проверяет согласие перед отправкой события. Убран обход согласия через `noscript`-пиксель Метрики.

Если localStorage недоступен, сайт и кнопки продолжают работать, а необязательная аналитика остаётся выключенной. Постоянно сохранить выбор в этом случае технически нельзя. QA перехватывает сторонние скрипты локально: проверены условия их загрузки, а не доставка событий в кабинеты сервисов. Юридическое соответствие не заявляется.

## Navigation, внутренние страницы и accessibility

Header/Footer общие для всех страниц. Добавлены доступ к статьям и cookie settings из footer. Все ссылки на секции с внутренних страниц ведут на `/#…`, logo ведёт домой; пустых href и отсутствующих внутренних anchors не обнаружено. Header остаётся обычным, как в утверждённом дизайне: искусственная sticky-механика не добавлялась.

Статьи, политика и оферта получили локальные Manrope/Onest, общие цвета, читаемую ширину 900 px, мобильные заголовки и отступы. Нового макета нет. Сравнение нормализованного текста каждой из шести внутренних страниц с `9e33135` показало точное совпадение; добавленные breadcrumbs исключены из этого сравнения.

Исправлены переход фокуса к первому пункту открываемого mobile menu и возврат фокуса к кнопке после закрытия отзыва в WebKit. У внутренних страниц появился общий видимый focus; навигации оглавления получили названия. Проверены один h1, иерархия заголовков, landmarks, alt, контраст, Escape, skip link, FAQ, вкладки тарифов, кнопки и ссылки. В WebKit для навигации по ссылкам использован Option+Tab — стандартный режим Safari на macOS без включённого полного доступа клавиатуры.

Существующие labels, aria-invalid, сообщения ошибок и успеха формы, фокус на сообщении и сохранение полей проверены без изменения кода формы. Успех и ошибка — только через локальный Playwright mock. Реальных заявок не было.

## Performance и CSS

- Удалён Google Inter из корневого layout. Сборка и отображение шрифтов больше не требуют Google Fonts. Существующие Manrope/Onest преобразованы без смены начертания в WOFF2; исходные TTF и лицензии сохранены. `onest-og.ttf` — статический вес 400 того же шрифта только для серверного OG renderer, не шрифт страницы.
- Главная уже состояла из Server Components; интерактивность оставлена только там, где нужна. Аналитика вынесена в отложенный клиентский chunk. Framer Motion из архивных секций не загружается публичной страницей.
- `next/image`, preload главной фотографии, lazy-loading остальных изображений и исходники отзывов сохранены; у footer logo добавлен точный `sizes="44px"`.
- Удалены пять неподключённых пакетов: `next-seo`, `next-sitemap`, `@mdx-js/react`, `remark-gfm`, `lucide-react`. Из lockfile ушли 73 пакета, версии оставшихся не изменились. Новых production dependencies нет.
- Общие брендовые переменные вынесены в `app/globals.css`, основной `--brand: #00d2f2` сохранён. Удалены повторные/конфликтующие legacy-правила для sections, grids, заголовков и мобильных изображений. CSS внутренних страниц теперь ограничен их контейнером; старый неимпортируемый `ui-kit.css` удалён. Каскад и responsive-правила living-school сохранены. Audit CSS module не нашёл безопасно удаляемых селекторов: предположительная чистка не проводилась.

Практический замер production-сервера: около 154 KB сжатого JS, 19 KB CSS и 138 KB WOFF2 на первую загрузку; два прежних локальных TTF передавали около 179 KB, дополнительно раньше подключался Inter. Точные ресурсы, три холодных браузерных контекста для 390/1440 и LCP/CLS — [smoke-performance.json](evidence/smoke-performance.json). CLS во всех шести замерах — 0. LCP на localhost не является прогнозом Core Web Vitals на реальном хостинге; Lighthouse score или полевые показатели не заявляются.
